Install it

  1. Download apb-install.rsc above.
  2. Upload it to the router: drag it into Files in WinBox, or scp apb-install.rsc admin@router:/
  3. Run /import file-name=apb-install.rsc
  4. Delete the file from the router. It contains the token.
  5. Check /log print where message~"APB" — you should see a rebuild complete within a few seconds, and this page will show the router as online.
  6. Add enforcement rules. The generated firewall example drops traffic from {{$d.ListName}}; review it before importing, because rule order matters.
